# 01-runtime-self-update — Runtime en self-update — data lineage

## Core chain
`semantic request -> schema/allow-list -> trusted source/state -> policy/safety -> Runtime en self-update executor -> private state/effect -> bounded evidence/result`

## Required trace fields
- component/subcomponent;
- semantic project/action identity;
- exact revision/version when applicable;
- safety/approval result;
- state/job revision;
- external/peer edge category;
- sanitized outcome/error category;
- build identity/audit evidence where applicable.
