# Runner-MCP failure taxonomy

Reuse AIfordable common classes and these Runner-MCP-specific refinements:

- CONFIG_MISSING / CONFIG_INVALID / PRIVATE_STATE_UNSAFE
- PROJECT_UNKNOWN / PROJECT_SOURCE_UNAVAILABLE / SOURCE_REVISION_MISMATCH
- TEST_PROFILE_UNKNOWN / TEST_QUEUE_SATURATED / TEST_TIMEOUT / TEST_OUTPUT_TRUNCATED
- MAILBOX_PROTOCOL / MAILBOX_REPLAY / MAILBOX_RATE_LIMIT / RESULT_DELIVERY
- FABRIC_PEER_UNAVAILABLE / PROTOCOL_INCOMPATIBLE / INTERFACE_INCOMPATIBLE / BUILD_IDENTITY_INCOMPATIBLE
- QUALIFICATION_POLICY_MISSING / QUALIFICATION_STALE / DISPOSABLE_TARGET_INVALID
- UPDATE_ARTIFACT_UNAVAILABLE / UPDATE_VALIDATION / UPDATE_INSTALL / UPDATE_RESTART_PENDING / UPDATE_RECOVERY
- DEPLOYMENT_PRECONDITION / MIGRATION_PRECONDITION / BACKUP_RESTORE
- APPROVAL_MISSING / EMERGENCY_STOP / RELEASE_LOCKED
- CI_GUEST_NOT_READY / CI_ENROLLMENT / CI_SECRET_HANDOFF
- SERVICE_NOT_RUNNING / SERVICE_RESTART / AUTOSTART
- TUNNEL_CONFIG / TUNNEL_PROCESS / TUNNEL_LOCAL_HEALTH / TUNNEL_END_TO_END
- AUDIT_WRITE / DIAGNOSTIC_REDACTION / BUILD_IDENTITY_MISMATCH
- ARTIFACT_DIGEST_MISMATCH / MIRROR_STALE / CUSTODY_UNAVAILABLE
- CI_INFRA / TEST_ASSUMPTION / UNKNOWN_ROOT_CAUSE

A failure record identifies the earliest proven layer, not merely the final MCP error.
